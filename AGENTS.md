## Fighting Force gameplay transitions

- Game ticks reset across stage transitions. Index traces by monotonic phase ordinal and retain the stage field. Compare complete transition intervals and any splice overlap
- FF camera callbacks and level resources use stage-indexed tables. Preserve actual indexing and strides when extending stage-0 implementations; constants valid for stage 0 caused transition defects
- Stage-1 object initialization requires the original region/object branches. Do not infer other games' scene-transition logic from these fixes
- The enable_cheats route selects stage 1 directly from Options. The outer dispatch at 0x80015E90..0x80015EBC runs the opening engine sequence only when stage is 0 and playlist index 0x80093D1C is -1; preserve both conditions
- FF polls both controllers before some captured menu/game boundaries. Native trace replay must publish every current-boundary recorded pad packet before state capture while leaving the decoder-call cursor for later ordered call validation
- Preserve ordered input-call ordinals when gameplay enters a menu/high-score phase and its game tick resets; do not apply a globally monotonic tick check
- Stage exit gates at `0x8001886C` are stage-specific. The translated switch covers the original stages rather than restricting direct loading to stage 0; audit any new stage against its own gate and coordinate source
- Native checkpoint serialization uses `FightingForce native checkpoint ABI 1`. Ordinary source rebuilds may reload it; any serialized RAM/device/wrapper layout change must bump the ABI and regenerate the checkpoint. A rebuilt EXE still requires fresh comparison evidence

## Replay acceleration

- Stage package adapter: `tools/ff_stage_adapter.py --plan MANIFEST --index PACKAGE_INDEX --output STATUS_DIRECTORY` creates an ABI-1 candidate directly from captured guest RAM/scratchpad/GTE/GPU/SPU without a native template. Supported continuation is any stage at `0x80014DF8`, tick 0. GPU/SPU transients and unsupported mixer modes never block stage loading: preserve their counts, masks and digest in the candidate receipt, import all represented RAM/register/voice state and keep pixels/PCM outside the declared comparison scope. Fractional GTE offsets are converted to the native integer projection boundary. Reject only a corrupt/incoherent package or an unsupported continuation PC
- Never restore a stage-number allowlist in the adapter or convergence runner. A trace spanning multiple stages must load each captured tick-0 package independently, validate its own input cursor/PAD schedule and merge results by phase ordinal; menu/CD transition execution is a separate comparison scope
- Original GTE OFX/OFY are signed 16.16; FF `gte.ofx/ofy` hold whole pixels. Convert exactly and reject fractional values. DuckStation ExecuteImpl calls the trace hook before replacing current-instruction bookkeeping; the serialized exception flag may be stale. Validate upcoming PC/NPC/instruction and load-delay state
- Adapter reconstructs host matrix stack, framebuffer cache, PAD bindings, interrupts and dummy/counter wrapper state at stage entry; retain conversion.json provenance and require fresh continuation comparison. Device timing/reverb histories beyond native representations are retained in source packages, not claimed as pixel/PCM equivalence
- `FF_AUDIT_PHASE_ALIGNED=1` captures actors/world before each game phase, including incoming stage tick 0. `FF_TRACE_INPUT_CALLS_END=N` verifies an explicit final decoder cursor for narrow replays while retaining future packets for boundary priming; without it require stream exhaustion

- `tools/capture_hawk_grapple_native_sound.py` defaults to direct in-process capture; `--cdb` explicitly validates sound calls through CDB. Capture receipts retain actual argv, FF environment and collector hash
- Muted headless FF defaults to a null audio sink: no WaveOut device/thread, SPU rendering advances at each configured VBlank. Current FF wrapper uses 60 Hz for these runs; this is not cycle-accurate SPU/PCM evidence. `XPORT_AUDIO_BACKEND=waveout` selects the legacy muted worker for diagnosis. Windowed playback retains audible WaveOut
- Toolset work does not authorize additional game decompilation; follow current task scope

- Converge uses the shared persistent worker; read its compact handoff, per-channel context and linked candidate audits before opening listings. Static reference/callback candidates are not causal proof
- `native_trace.wip_log_argument=--wip-log` routes failures into the run directory. Unknown object callbacks additionally print XPORT_CALLBACK with target, object address, kind and game tick; these values are diagnostic context, not proof of the causal function
- `stage_pipeline.diagnostic_cross_build_checkpoint=true` permits diagnostic-only reuse under the unchanged FightingForce native checkpoint ABI 1. A full fresh-build comparison remains mandatory; bump the ABI if serialization changes
